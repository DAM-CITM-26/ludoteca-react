# Ludoteca

Un catálogo de juegos de mesa: descubres juegos, los guardas en tu ludoteca y apuntas tus partidas.
Es el **ejemplo de clase** de DAM 2026-27: la referencia de la Ludoteca (HTML, CSS y JavaScript), hecha en React sprint a sprint.

## Cómo arrancarla

```bash
npm install
npm run dev
```

Y abrid la dirección que aparece (con las herramientas de desarrollo en modo móvil).

## Carpetas

| Carpeta | Qué hay |
|---|---|
| `src/components` | Los componentes (átomos, moléculas y organismos) |
| `src/pages` | Una pantalla por fichero |
| `src/data` | Los datos de ejemplo |
| `src/utils` | Las funciones puras: filtrar, ordenar, calcular |
| `docs` | El modelo de datos y los componentes de cada pantalla |

## Cómo leer este repositorio

Cada tarjeta del Sprint 1 es una rama o varias (`s1-vite`, `s1-datos`…), que entran en `main` con un merge.
En la pestaña **Commits** de GitHub se ve, paso a paso, cómo cada función de la referencia pasa a ser un componente de React.
